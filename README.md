# the-things-left-behind
A psychological horror prototype in Unreal Engine 5 exploring observation, environmental storytelling, and tension-driven horror systems.

The project explores horror through observation, environmental storytelling, and player psychology instead of traditional enemy encounters.

---

## Core Features

- Observation-based horror
- Dynamic environmental changes
- Hidden Presence System
- Photography mechanic
- Reality Drift
- Psychological tension
- Modular level design

---

## Engine

Unreal Engine 5

---

## Current Status

🟡 Pre-Production

Currently focusing on:

- Concept Art
- Level Blockout
- Horror Systems
- Gameplay Prototype

---

## Design Philosophy

Fear should come from uncertainty.

The player should never know if the mannequins are alive.

The game never confirms it.
